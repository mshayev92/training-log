# Training log

An offline-first PWA for a 10-week strength and athletic block: five sessions a
week across two phases, a deload, and a retest. Log sets, bodyweight and gym
notes from a phone with no signal, then install it to the home screen so it
opens like an app.

## Running it

```sh
npm install
npm run dev      # http://localhost:5173 — service worker is live in dev too
npm run build    # production build into dist/
npm run preview  # serve dist/ to check install + offline behaviour
```

`npm run icons` regenerates the icon set from `scripts/generate-icons.mjs`. The
output is committed, so a normal build never needs it.

## What makes it a PWA

- **Installable.** `manifest.webmanifest` (generated by `vite-plugin-pwa`)
  declares a standalone, portrait, dark-themed app with 192/512 icons plus a
  maskable variant, so Android launchers crop it without clipping the glyph.
  iOS gets `apple-touch-icon` and the `apple-mobile-web-app-*` meta tags.
- **Works offline.** A Workbox service worker precaches every build asset and
  falls back to `index.html` for navigations. After one visit the app opens
  with the network off — verified by loading it, going offline, and reloading.
- **Updates on your terms.** `registerType: "prompt"`: a new version announces
  itself in a toast and waits, rather than reloading the page mid-set.
- **Local data.** Sessions, bodyweight and notes are written to `localStorage`
  behind `src/storage.js`, debounced 500ms. Nothing leaves the device and there
  is no account or backend. `navigator.storage.persist()` is requested on start
  so the browser is less likely to evict the log under storage pressure.
- **Fits the screen.** `viewport-fit=cover` with `env(safe-area-inset-*)` on the
  header, tab bar and rest timer, so nothing hides behind a notch or home bar.

## Deploying

Any static host works — the build is plain files in `dist/`. The service worker
needs HTTPS (or `localhost`).

Serving from a subpath, such as GitHub Pages at `/training-log/`, needs the base
path at build time so the manifest, scope and precache URLs match:

```sh
BASE_PATH=/training-log/ npm run build
```

## Caveats

- The log lives only in that browser's storage. Clearing site data, or
  switching browsers or devices, loses it. The Data tab exports everything to a
  JSON file and restores from one, but nothing syncs on its own — backing up is
  a thing you have to remember to do.
- Restoring replaces the whole log rather than merging, so the confirmation
  names what is in the file and what is about to be overwritten.
- `window.storage`, which the original single-file component expected from its
  host, is gone; `src/storage.js` provides the same async API.
